# 大同大學資訊工程系｜無人載具研究中心 (Unmanned Vehicles Research Center)

**啟動智慧，領航未來：人工智慧與自主系統開發的創新搖籃**

本專案為「大同大學資訊工程系無人載具研究中心」的官方網站展示頁面。

## 💡 中心簡介

本中心由 **卓世明 副教授 (Shih-Ming Cho)** 主持，聚焦於**「智慧感知」**與**「自主控制」**兩大核心，致力於開發能在複雜環境中執行精準導航與作業的頂尖無人系統。我們秉持「理論與實作並重」的跨領域教學理念，帶領學生打破硬體開發與軟體演算法的界線，從底層邏輯到高階 AI，培育具備全端系統整合能力的次世代科技人才。

## ⚙️ 核心技術領域

- **多重感知與影像辨識**：運用 RGB-T 異質融合技術及 Amodal Generative Augmentation，在複雜且具遮蔽的環境中，實現精準的靈長類動物偵測與辨識能力。
- **協同防護網路**：建立單機無人機 (UAV) 與地面感測網路 (GSN) 的無縫協同架構，落實農漁牧場域之全方位即時防護與監控。
- **智慧自動化控制**：基於 STM32 控制核心與 RTOS 實時作業系統，開發具備自動化清洗功能之智慧魚菜共生系統，以及高效能之聲光驅趕裝置。

## 🚀 重點發展項目

- **智慧自走車實踐 (UGV)**：多感測器融合應用 (LiDAR/Vision)、實時嵌入式系統 (RTOS) 控制、人工智慧物件偵測與追蹤。
- **無人機開發設計 (UAV)**：飛控系統設計、精準定位技術 (UWB)、長程通訊鏈路 (LoRa)。

## 🏆 研究成果與亮點

- **專利與發明**：多項新型專利核准與發明公開，包含無人機自動驅趕系統、智慧型農地防護系統等。
- **代表性學術論文**：多次發表於國際頂尖期刊與國際研討會（如 CMC, ICCCM, BIOTC, EESP, ECICE 等），展示在 AIoT 跨領域技術、智慧防護系統上的具體研發與商品化量能。
